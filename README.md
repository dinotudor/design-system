# SkiroLiro design system

This repository holds the visual identity, design tokens, and UI/UX guidelines for all SkiroLiro apps.

Start with [`DESIGN.md`](DESIGN.md).

## Files

- `DESIGN.md`: brand, logo rules, color roles, typography, spacing, web and mobile notes
- `tokens.json`: design tokens in DTCG format (source of truth)
- `tokens.css`: CSS variables generated from `tokens.json`
- `guidelines/UI.md`: layout, components, motion, checklist
- `guidelines/UX.md`: principles, flows, copy, accessibility, collaboration patterns
- `logo/*.svg`: final logos (text converted to outlines)
